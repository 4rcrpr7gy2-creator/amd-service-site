# AMD-service — сайт-визитка

Готовый адаптивный сайт на HTML, CSS и JavaScript. Не требует сборки и платных библиотек.

## Файлы
- `index.html` — содержание сайта
- `styles.css` — дизайн и адаптация под мобильные устройства
- `script.js` — мобильное меню и текущий год в подвале
- `favicon.svg` — иконка сайта

## Как посмотреть
Откройте `index.html` в браузере. Для локального просмотра интернет не обязателен, кроме загрузки шрифта Google Fonts.

## Как опубликовать бесплатно через GitHub Pages
1. Создайте аккаунт на https://github.com/ (если его ещё нет).
2. Создайте новый публичный репозиторий, например `amd-service-site`.
3. Загрузите в корень репозитория все четыре файла из этой папки.
4. Откройте **Settings → Pages**.
5. В разделе **Build and deployment** выберите **Deploy from a branch**, ветку `main` и папку `/ (root)`, затем нажмите **Save**.
6. Подождите несколько минут. В разделе Pages появится адрес сайта вида `https://ВАШ-ЛОГИН.github.io/amd-service-site/`.

## Домен
Варианты домена для проверки при покупке:
- `amd-service.ru`
- `amdservice-sochi.ru`
- `amd-service-sochi.ru`

Это только идеи: доступность доменов не проверена. Покупайте домен у регистратора после проверки доступности и продления цены. Для подключения своего домена к GitHub Pages:
1. В настройках **Settings → Pages → Custom domain** введите купленный домен и сохраните.
2. В панели регистратора добавьте DNS-записи, которые GitHub Pages укажет в своей актуальной инструкции. Для поддомена `www` обычно используется CNAME на `ВАШ-ЛОГИН.github.io`; для корневого домена добавляются A/AAAA-записи из документации GitHub.
3. После обновления DNS включите **Enforce HTTPS**, когда эта опция станет доступна.

Актуальная документация GitHub Pages: https://docs.github.com/pages
